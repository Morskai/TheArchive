# 使用指南

## 添加影片

在“设置”中添加影片目录，主动发起扫描。分类目录、演员名目录、影片目录和根部视频可以混合；同一目录的直属视频归为一张影片卡片，多个视频作为版本或分集，子目录独立处理。

封面优先选择同目录 poster 图片，格式优先级为 JPG、JPEG、PNG、WebP、AVIF，名称不区分大小写。只有一个直属视频时可以使用视频同名图片；多个视频的卡片使用 poster。详情播放项可显示视频同名图片。

启动、切页和磁盘重连不会自动扫描。文件变动后，在设置中重新主动扫描；扫描不修改媒体原文件，也不根据目录名称自动创建演员。

## 浏览与整理

在影片库中按片库、关键词、评分、收藏和标签筛选。清除筛选保留所选片库，只清搜索、评分、收藏及标签条件。

影片卡片可进入详情或播放；详情中可编辑片名、编号、评分、收藏、标签、首选版本和出演关系。删除影片只删除软件记录，不删除媒体文件，之后主动重扫可再次收录。

影片封面比例按片库分别保存；“全部片库”有自己的总览比例。演员照片使用统一比例。两者均可切换卡片密度；设置中可选择图片裁切或完整显示。

## 演员资料与翻牌

在演员库选择“新增演员”，可以手动添加，也可以扫描包含 actor.info 的目录。演员不要求关联影片；照片和个人信息可以留空，出生年月可只填年份或填写年月。

姓名与别名用于导入匹配。完整身份唯一一致时默认更新，无候选时默认新增，部分重名和同批冲突需要明确选择；不会凭照片、旧文件 ID 或历史目录认人。出演清单只有精确匹配后才补关联。完整契约与示例见[演员资料格式](ACTOR_INFO.md)。

照片只记录所选原图的路径和指纹，不永久复制进软件数据库。移动或删除原图后，已有缓存可能仍可显示，但清缓存后需要原图可读。更换照片在演员编辑窗口操作，软件不改写原图片。

翻牌每轮最多选择八位不同演员，优先有照片者；演员数量不足时显示实际数量，不补重复。点击揭晓，再次点击可查看详情，返回保留当前牌桌；支持“翻开剩余”和重新洗牌。

导出演员资料会在所选位置建立 ActorExports 目录，生成 actor.info 及可用照片副本。已有照片路径但原图不可读时会拒绝不完整导出。导出副本应保存在软件资料目录之外；重装后先扫描影片，再导入演员。演员标签及完整设置请使用软件备份恢复。

## 播放

在设置中选择内置播放器或自定义外部播放器。内置播放器支持暂停、定位、音量、倍速、字幕、音轨、选集及独立窗口；一次只维护一个播放会话。

播放历史记录成功发起的播放，不代表看完影片或保存了观看进度。

## 片名翻译与界面语言

片名翻译支持 DeepL、Google Cloud Translation、Microsoft Azure Translator 和百度翻译开放平台。配置服务与系统凭据、测试连接后，手动检测并勾选需要翻译的条目；启动与扫描不会自动调用服务。外部服务可能计费，密钥不随备份导出。详见[翻译说明](TRANSLATION.md)。

在“设置 → 界面 → 界面语言”选择简体中文、繁体中文、英语或日语，保存后立即生效。片名、姓名、标签和路径保持原文，片名翻译目标仍为简体中文。

## 备份、恢复与图片缓存

主动备份用于保存软件数据库与非秘密设置，不包含媒体原件、演员照片原图、派生缓存和翻译密钥。请另行保管媒体与原图片。恢复会核对兼容性并保护现有资料，照片路径仍需在本机可读；旧备份的历史照片存储会按当前规则迁移。

“清空图片缓存”只删除可重建缓存，图片之后按需读取；原图不可读时可能显示占位。加载失败的图片本次运行不反复重试，成功扫描、清缓存或明确保存照片会按相应范围允许重试。

“恢复初始状态”会清除软件资料、设置、配置、凭据、缓存和内部保护，唯一保留完整标题翻译记忆；媒体原件、外部 info、既有导出和主动备份不动。这与“清除翻译记忆”是两个操作。执行前核对确认内容并备份；不要将恢复或清除功能当成常规修复手段。

## 问题与诊断

问题中心检查封面缺失和同片库实际卡片编号重复；筛选与处理只作用于对应可见范围。可以在设置中打开本地诊断日志目录或导出诊断文件，提交问题前仍应自行检查内容，避免附带真实片库和密钥。

默认关闭主窗口会收起到托盘；可在设置中调整退出方式。重复启动会恢复已有窗口。
